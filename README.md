# Etch-A-Sketch
A browser-based digital Etch-a-Sketch toy built using HTML, CSS, and JavaScript, completed as part of <a href="https://www.theodinproject.com/">The Odin Project</a> curriculum. The goal of this project was to create a sketchpad where users can draw on a grid, clear their canvas, and dynamically resize the grid. It heavily tests foundational JavaScript DOM manipulation skills, event handling, and CSS Flexbox layout.

# Live Demo
https://sukakude.github.io/etch-a-sketch-project/

# Key skills learned
- Dynamically creating, styling, and appending DOM elements using JavaScript loops.
- Managing event listeners efficiently
- Working with CSS Flexbox to ensure responsive and fluid scaling of child elements inside a container.
- Debugging layout bugs when calculating cell sizes dynamically based on user input.
